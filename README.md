# FitBuddy - AI Fitness Coach 💪

FitBuddy is an AI-powered fitness assistant built using Google Gemini API.

## Description
This project creates personalized workout and diet plans based on user inputs like age, weight, height, fitness goal, and food preference (Veg/Non-Veg).

## Features
- 🏋️ Weekly workout schedule with exercises, sets, and reps
- 🥗 Daily diet plan with calories and protein count
- 🎯 Supports Weight Loss and Muscle Gain goals
- 🍱 Veg and Non-Veg diet options
- 🤖 Powered by Google Gemini 1.5 Pro

## Tech Stack
- Python
- Streamlit
- Google Generative AI (Gemini API)
